# Gallery

A privately hosted image and video collection. You can favorite, add a title, and a description to the images and
videos.

## Features

- You can upload images and videos to the site.
- The files will automatically get a thumbnail version.
- The files can be favorited.
- The files can have a title and description in plain text.

## Roadmap

- Image merging based on hash
- Image merging based on similarities
- Tagging system
- Namespaces for the tags
- Image cropping
- Video cropping
- Video thumbnail choosing
- File conversions
- File retrieval
- Face recognition and grouping
- File grouping
